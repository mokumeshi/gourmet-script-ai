# 鍋振りチャーハン：2Dアニメ実験

素材画像・外部ライブラリ・3Dを使わず、HTML Canvas 2Dだけで描く6.4秒ループの料理カットです。中華鍋の振り、放物線を描く米粒・卵・ネギ・叉焼、炎、湯気、油の照りを同期させています。単一の `index.html` なのでファイルをブラウザで開くだけで再生できます。

## 使い方

- `index.html` をChrome、Safari、Firefoxなどで開く。
- 一時停止してスライダーでコマを確認し、`このコマをPNG保存` で1280×720画像を出力。
- 録画はブラウザの画面収録、またはPlaywrightなどでCanvasをフレーム単位で取得。映像化の際は音を別トラックで重ねてください。

## 調整点

- ループ尺：`DURATION` と `tosses` 配列
- 米粒の密度：`rice` 配列の `length`（既定650）
- 飛ぶ具材の量：`airborne` 配列の `length`（既定175）
- 熱気：`steam` 配列と `steamLines()`
- 配色・描線：`backdrop()`、`wok()`、`drawGrain()`

疑似乱数の種を固定し、再生や書き出しで具材の配置が変わらないようにしています。1920×1080や4K出力にはCanvasの内部解像度と描画座標の倍率を合わせて変更できます。
