# チャーハンができるまで — Canvas 2Dアニメ

## 完成までの28秒版

- **再生用ソース**：[full-process.html](full-process.html) — ダウンロードしてブラウザで開く。
- **映像**：[fried-rice-full-process.mp4](fried-rice-full-process.mp4) — 1280×720 / 24fps / 28秒 / 音声なし。
- **完成カット**：[full-poster.png](full-poster.png)

素材画像・3D・外部通信を使わず、HTML Canvas 2Dの線、面、粒子で描画します。白い料理人の袖と手、卵、米、卵のかけら、叉焼、ネギ、中華鍋、皿もすべてコードによる作画です。

| 時間 | 工程 |
|---|---|
| 0–4秒 | 卵を割り、黄身と白身を油の入った中華鍋へ落とす |
| 4–7秒 | お玉で卵をほぐす |
| 7–10秒 | 茶碗からご飯を入れる |
| 10–12秒 | 叉焼とネギを入れる |
| 12–14秒 | 調味料を加えて混ぜ、黄金色にする |
| 14–20.5秒 | 鍋を4回振って米と具材を返す |
| 20.5–24秒 | 鍋を傾けて皿へ盛り付ける |
| 24–28秒 | 完成の寄り、仕上げのネギ、湯気、照り |

再生／一時停止、最初から、時間の移動、PNG保存に対応。スライダー操作時は一時停止します。28秒の終わりから最初へ再生が戻ります。完成から卵割りへはカットで戻るため、連続した動作としてのシームレスループではありません。

## 映像の再書き出し

ブラウザ再生にインストールは不要です。映像ファイルを再生成する場合のみ、Node.jsとFFmpegを用意し、このフォルダで以下を実行します。

```bash
npm install
npm run render
```

`render-full.cjs` はHTML内の描画処理 `window.FriedRice.renderAt(seconds)` を同じ時間指定で呼び出します。映像と完成PNGを再生成します。乱数seedを固定しており、同じ環境・コードで具材配置を再現できます。

## 構成を調整する箇所

- `kitchenScene()`：投入・炒め・鍋振り
- `crackEgg()`：殻を開く、卵が落ちる
- `pourRice()` / `pourIngredients()`：ご飯・具の投入
- `tossTimes` / `tossState()`：鍋振りの時刻と動き
- `plating()`：中華鍋から皿へ移す
- `hero()`：完成カット
- `mound()` / `grain()`：米・卵・叉焼・ネギの作画
- `stageAt()`：プレイヤーに表示する工程名（映像には入りません）
